What this system does

This dashboard implements the Adaptive Multi-Model Detection Layer — replacing the base paper's fixed XGBoost classifier with an ensemble of 5 ML models that dynamically reweight based on per-round performance.

Adaptive Detector Score (ADS)

Each model is scored on 4 components (equal 25% weight):

  • F1-score — current round's macro-F1 on validation
  • Recall — current round's recall (configurable importance)
  • Stability — 1 - min(std/mean) of F1 over rolling window
  • Historical — exponential moving average of F1 (alpha=0.7)

Weights are normalized so they sum to 1.0 each round.
